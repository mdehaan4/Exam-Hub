# Exam Hub

A self-contained, single-file revision app for technical certification exams, styled in Capgemini's brand blues.

Open `index.html` in any browser — no build step, no server, no dependencies.

## Modes

- **Exam Mode** — traditional multiple-choice quiz through all 20 questions per subject, with an explanation after each answer, a live timer, and a pass/fail-at-75% results screen with a category-by-category breakdown.
- **Arcade Mode** — a retro Space Invaders-style shooter where you shoot the alien ship carrying the correct answer, with a weapon that upgrades as you get questions right.

## Subjects

- GitLab Fundamentals Associate
- PostgreSQL Fundamentals
- AWS Certified Cloud Practitioner
- AWS Certified AI Practitioner
- UK Tax Fundamentals

Each subject has 20 questions across 5 topic categories.
